
#### /sys/devices里的风扇

```bash
sudo touch /etc/udev/rules.d/99-fan-control.rules

# 查看udev属性
udevadm info --query=all --path=/sys/devices/pwm-fan

# 需要控制的是 /sys/devices/pwm-fan/target_pwm
# 写入
SUBSYSTEM=="pwm-fan",ATTRS{name}="pwm-fan",MODE="0660",GROUP="gpio"

# 载入
sudo udevadm control --reload
sudo udevdam trigger

# 将普通用户加入该组
sudo usermod -aG gpio lzq

# 查看
ls -l
```
直接 sudo chmod 777 /sys/devices/pwm-fan/target_pwm
