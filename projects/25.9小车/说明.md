#### tx2 nx基本说明
- 开机直接进入界面，不需要输入密码
	用户名：nx
	密码：nx

- 设备查看工具
  sudo jtop
  可以查看cpu,gpu,内存等使用情况

- ~/camera 存放查看深度图的代码
- ~/car 存放一些说明文件
- ~/softwares 存放算法库
- 其他文件夹为系统自带的

#### 摄像头查看深度图
```bash
# 第一步
# 打开相机
roslaunch astra_camera astra_pro.launch

# 第二步
# 运行中心点深度检测代码，画面中心点距离小于0.8会有输出
roslaunch read_depth_image read_depth_image.launch

# 第三步
# rviz查看画面
roslaunch read_depth_image rviz.launch

# 以上三步也可以被整合到一个启动文件
roslaunch read_depth_image whole.launch
```
